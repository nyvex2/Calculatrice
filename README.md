# Calculatrice

Une calculatrice educational crée par l’élève **Adam Eddahbi** en ligne simple réalisée avec TypeScript.

## Fonctionnalités

- Addition
- Soustraction
- Multiplication
- Division
- Pourcentage
- Nombres décimaux
- Effacement du calcul
- Affichage des résultats
- Historique des calculs

## Technologies utilisées

- HTML
- CSS
- TypeScript
- Vite

## Installation

1. Télécharger ou cloner le projet.
2. Installer les dépendances :

```
npm install
```
# Si vous utiliser cette repository et le lancer:
```
npm run dev
```
Ouvrir l’adresse indiquée par Vite dans le navigateur.

# Compilation

Pour créer la version finale du site :
```
npm run build

```
Les fichiers seront créés dans le dossier **dist**.

# Utilisation
Entrez un calcul avec les boutons de la calculatrice, puis appuyez sur = pour obtenir le résultat.
